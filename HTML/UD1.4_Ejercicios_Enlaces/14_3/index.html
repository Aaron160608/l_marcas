1. Qué es HTML

HTML (HyperText Markup Language) es el lenguaje que se usa para crear la estructura de las páginas web. No es un lenguaje de programación, sino un lenguaje de marcado: sirve para indicar qué es cada parte del contenido, como un título, un párrafo, una imagen o un enlace.

Cuando abres una web, el navegador lee el código HTML y lo convierte en la página que ves. Por eso es la base de todo el desarrollo web, y se suele combinar con CSS, que se encarga del aspecto, y con JavaScript, que añade comportamiento.

2. Estructura de una página

Todo documento HTML empieza con la declaración <!DOCTYPE html>, que indica al navegador qué versión del lenguaje se usa. Después se escribe la etiqueta <html>, que contiene todo lo demás y se divide en dos partes principales.

La primera es <head>, donde van datos que no se ven directamente, como el título de la pestaña y la codificación de caracteres. La segunda es <body>, que contiene todo lo que el usuario ve en pantalla: textos, imágenes, enlaces y listas.

3. Etiquetas más habituales

Los títulos se escriben con las etiquetas <h1> a <h6>, donde <h1> es el más importante. Los párrafos usan <p>, y para destacar texto puedes usar <strong> (importante) y <em> (énfasis).

Para crear listas se usan <ul> (sin orden) o <ol> (ordenadas), con elementos <li>. Las imágenes se insertan con <img> y los enlaces con <a>, usando los atributos src y href respectivamente.

4. Cómo practicar

La mejor forma de aprender HTML es escribir código a diario. Empieza con páginas sencillas, como una presentación personal, y ve añadiendo elementos poco a poco: primero textos, luego imágenes, listas y enlaces.

Usa un editor como Visual Studio Code con la extensión Live Server, para ver los cambios al guardar. Si algo no funciona, revisa que hayas cerrado todas las etiquetas y consulta la documentación de MDN Web Docs.
