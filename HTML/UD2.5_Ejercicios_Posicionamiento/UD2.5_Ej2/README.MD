# Respuesta Ejercicio 2: Menu que se queda fijo

# Diferencia entre position: sticky y position: fixed

*position: sticky:* El menu se comporta como un elemento normal en el flujo de la pagina hasta que la pantalla llega a su altura al hacer scroll. En ese momento se engancha a la parte superior y te acompaña. Lo bueno es que conserva el espacio original dentro del documento y el contenido de abajo no se solapa.
*position: fixed:* El elemento se saca por completo del flujo normal de la pagina y se queda pegado de forma permanente a la pantalla. Al hacer esto, el contenido que estaba debajo sube de golpe y se mete por debajo del menu, perdiendo el espacio que antes ocupaba.
