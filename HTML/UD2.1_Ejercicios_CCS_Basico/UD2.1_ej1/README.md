# Respuestas Ejercicio 1

# ¿Cual de las tres formas es la mas comoda si tuvieras que cambiar el color del titulo en 10 paginas?
La mas comoda es la tercera forma hoja de estilo externa con enlace. Si tengo 10 paginas vinculadas al mismo archivo, solo seria necesario modificar la regla una sola vez en el archivo CSS para que se cambie automaticamente a las 10 paginas.

# ¿Por que se desaconseja la primera forma?
Porque mezcla el contenido HTML con la presentacion visual, la dificulta del mantenimiento, ya que habria que modificar elemento por elemento en cada archivo HTML, aumenta el tamaño del archivo HTML.
